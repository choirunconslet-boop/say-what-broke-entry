A single line of software error copy that tells the user the brutal truth about what went wrong — and makes them laugh on the way. The program (`main.ts`, pure Node.js standard library) writes the line to `/output/entry.txt`.

> "The database is fine. The password expired at 3 a.m. and told no one. Update it in the vault, not on a sticky note on the monitor."
